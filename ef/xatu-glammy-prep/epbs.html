Existing Events to Modify

BeaconBlock Events MODIFIED

BEACON_API_ETH_V2_BEACON_BLOCK, ..._EVENTS_BLOCK, ..._VALIDATOR_BLOCK

Block body no longer contains execution_payload, blob_kzg_commitments, or execution_requests. Has signed_execution_payload_bid and payload_attestations instead.

ClickHouse: New columns: builder_index, bid_value, execution_payment, payload_present

Transaction / Withdrawal / BAL Derivers MODIFIED

Transactions, withdrawals, and BALs now in ExecutionPayloadEnvelope. Cannon derivers must source from envelope, not block body.

Attestation Events — Index Semantic Change MODIFIED

Index field repurposed: 0 = same-slot / payload not present, 1 = payload present.

DataColumnSidecar — Structural Change MODIFIED

Removed: signed_block_header, kzg_commitments, kzg_commitments_inclusion_proof. Added: slot, beacon_block_root.

Approach: Additive only. New columns, NULL for Fulu rows.

Fork Choice Dumps MODIFIED

Tracks PayloadStatus per node: EMPTY (0), FULL (1), PENDING (2). New Store fields: payload_states, payload_timeliness_vote, payload_data_availability_vote.

Withdrawal Events MODIFIED

get_expected_withdrawals now includes builder withdrawals via BUILDER_INDEX_FLAG = 2^40.
